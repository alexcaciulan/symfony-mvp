Reguli respectate în toate cele trei ecrane

  • Gutterul tipărește tipul termenului, nu un verdict de ireversibilitate. Cuvântul „ireparabil” nu apare nicăieri.
  • Banda debitorului se numește „Termen debitor împlinit”, nu „Poți depune”, și nu este verde.
  • Contoarele numără dosare, nu termene, și se calculează pe coada de dedesubt, niciodată printr-un SELECT separat.
  • Nicio sumă „recuperată” și nicio sumă „sub risc”: eticheta este „principal pretins”.
  • Trunchierea se declară explicit în subsolul cozii, niciodată tăcut.
  • Regulă globală :focus-visible, zero animație infinită, gardă prefers-reduced-motion.
  • Listă închisă de câmpuri pe rând: fără CNP, adresă, CUI sau date de contact.
  • Disclaimer permanent: verificarea termenului și decizia procedurală rămân ale avocatului.

Ce nu este mockup-uit în v3

v3 acoperă exclusiv panoul de lucru. Restul aplicației rămâne pe v2: autentificare, wizardul de creare dosar, vederea de dosar cu cele cinci taburi și pagina de termene. Link-urile din mockup-urile v3 duc înapoi în ecranele v2 acolo unde navigarea o cere.
